# \# AgriMind AI – Smart Agriculture Advisory Platform

# 

# \## Project Overview

# AgriMind is a smart agriculture platform designed to help farmers

# monitor field conditions and manage irrigation efficiently using

# IoT-based sensors, automation and remote monitoring.

# 

# \## Key Features

# \- Real-time soil moisture monitoring

# \- Temperature and humidity monitoring

# \- Rain detection

# \- NPK soil nutrient monitoring

# \- Automatic and manual irrigation control

# \- Water flow monitoring

# \- Live camera monitoring

# \- Remote monitoring through Blynk IoT

# 

# \## Hardware and Technologies

# \- Arduino Uno

# \- ESP32

# \- ESP32 Camera Module

# \- Soil Moisture Sensor

# \- DHT11 Sensor

# \- Rain Sensor

# \- NPK Sensor

# \- Water Flow Sensor

# \- Relay Module

# \- DC Water Pump

# \- Blynk IoT

# 

# \## Repository Structure

# 

# \- Arduino\_Uno\_Scrolling\_Text\_Code/

# \- Esp32\_Main\_Code/

# \- ESP32\_S3\_Cam\_code/

# 

# \## System Architecture

# The sensors collect field data and send readings to the

# ESP32 controller. The controller manages irrigation and

# communicates monitoring data to the Blynk dashboard.

# The camera module provides remote visual monitoring.
